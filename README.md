# Novelia Studio

Escribe, planifica y publica tus novelas. App personal de Marta Lobo.

Abre **https://martalobo82.github.io/novelia-studio/** en Chrome y pulsa «Instalar» en la barra de direcciones.

Tus textos no se guardan aquí: viven solo en tu navegador (IndexedDB). Este repositorio solo contiene el código de la app.


## Planner

En la carpeta `planner/` está el **Planner** (antes «Planner mensual» de Excel), una app aparte: **https://martalobo82.github.io/novelia-studio/planner/**. Se instala por separado y guarda sus datos aparte.
